Para activar el seguimiento de visitas, carritos y clics en WhatsApp necesitas conectar Vercel KV.

Pasos:
  1. Ve a Vercel Dashboard → tu proyecto → Storage → conecta un KV.
  2. Vercel añade automáticamente KV_REST_API_URL y KV_REST_API_TOKEN.
  3. Redespliega el proyecto para aplicar las variables.
  4. Las analíticas empezarán a registrarse con las próximas visitas.
